# FinSight — AI Financial Dashboard

A full-featured financial management dashboard for small businesses, with multi-currency support and AI-generated insights.

**Live Demo:** https://fin-sight-beta-pink.vercel.app
**Source:** this repo

## What it does

- **Multi-currency support** — PKR, USD, GBP, AED
- **Inventory tracking**
- **Receivables & payables management**
- **AI-powered business insights** based on real financial data
- **PDF report export**
- **Interactive charts** for financial trends
- Dark glassmorphism UI designed for daily use

## Tech Stack

- Next.js + TypeScript
- Tailwind CSS
- Recharts for charts
- jsPDF + html2canvas for PDF export

## Getting Started

```bash
git clone https://github.com/awanzain026-cmyk/FinSight.git
cd FinSight
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
